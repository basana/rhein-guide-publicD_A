# Map Navi Prototype 0.1

Это изолированный экспериментальный прототип общего ядра Map Navi. Он создан в отдельной ветке и **не подключён к действующему приложению**.

## Что проверяет

- разделение трёх состояний: GPS, Active Map Intent и View Mode;
- категории замков, городов и достопримечательностей;
- поиск по названию и населённому пункту;
- выбор конкретного объекта;
- прямое расстояние по формуле гаверсинуса;
- Follow / Free View без сброса выбранной категории или объекта;
- одинаковый результат при последовательностях «GPS → категория» и «категория → GPS».

## Что использовано из действующего проекта

Файл \`profiles/rhine.json\` сформирован как снимок 22 объектов с координатами из \`index.html → castles[]\`. Тексты SAY THIS и первые фотографии взяты из тех же записей. Снимок предназначен для прототипирования и не заменяет исходный каталог.

В исходном \`index.html\` массив \`pois[]\` пока пуст: кафе и сувенирные точки показаны только как предусмотренный механизм. Поэтому в прототип не добавлены вымышленные туалеты, аптеки, кафе или другие практические объекты.

## Как запустить локально

Из корня репозитория:

\`\`\`bash
python3 -m http.server 8000
\`\`\`

Затем открыть:

\`\`\`
http://localhost:8000/map-navi-prototype/
\`\`\`

Для тестов логики (Node.js 18+):

\`\`\`bash
node --test map-navi-prototype/tests/core.test.mjs
\`\`\`

Страница использует Leaflet и тайлы OpenStreetMap через интернет. GPS работает только в поддерживаемом браузере и в защищённом контексте (обычно HTTPS или localhost).

## Важные ограничения

- Это отдельная тестовая страница, а не новая версия \`index.html\`.
- Исходные \`index.html\`, \`sw.js\`, \`manifest.json\`, фотографии и маршруты не изменяются.
- В прототипе пока нет подтверждённых практических POI, реальной маршрутизации, офлайн-тайлов, платёжных функций, Tourist/Guide Mode и полной карточки из действующего приложения.
- Профиль содержит копию части данных. Перед интеграцией потребуется единый источник данных или адаптер, чтобы не допустить расхождения.
- Ветка не публикуется автоматически через GitHub Pages. Переключать источник Pages с \`main\` на эту ветку нельзя: это может заменить действующий сайт. Для проверки на iPhone потребуется отдельный безопасный preview-способ.

## Принцип безопасности

Никакие изменения этого прототипа не влияют на действующий сайт, пока его файлы отдельно не подключены к \`index.html\`. Перенос в основное приложение и публикация требуют отдельной проверки и согласования.
